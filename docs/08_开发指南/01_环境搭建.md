# 环境搭建

## 1. 系统要求

### 1.1 硬件要求
  - **CPU**：至少4核，推荐8核及以上
  - **内存**：至少8GB，推荐16GB及以上
  - **磁盘**：至少50GB可用空间
  - **网络**：支持以太网或Wi-Fi，车载环境推荐TSN网络

### 1.2 软件要求

| 平台 | 版本要求 | 推荐配置 |
|------|---------|----------|
| Linux | Ubuntu 20.04+ | 4核CPU，8GB内存，50GB磁盘 |
| QNX | QNX 7.1+ | 4核CPU，4GB内存，30GB磁盘 |
| Windows | Windows 10+ | 4核CPU，8GB内存，50GB磁盘 |
| macOS | macOS 10.15+ | 4核CPU，8GB内存，50GB磁盘 |
| VxWorks | VxWorks 7.0+ | 4核CPU，4GB内存，30GB磁盘 |
| AUTOSAR | AUTOSAR 4.3.1+ | 4核CPU，4GB内存，30GB磁盘 |

## 2. 依赖项安装

### 2.1 Linux平台

#### 2.1.1 Ubuntu/Debian

```bash
# 更新系统
sudo apt update && sudo apt upgrade -y

# 安装基础依赖
sudo apt install -y build-essential cmake git

# 安装序列化库
sudo apt install -y libprotobuf-dev protobuf-compiler libflatbuffers-dev

# 安装日志库
sudo apt install -y libspdlog-dev

# 安装网络库
sudo apt install -y libboost-all-dev

# 安装安全库
sudo apt install -y libssl-dev

# 安装其他依赖
sudo apt install -y libncurses5-dev

# 安装TSN支持（可选）
sudo apt install -y libtsn-dev
```

#### 2.1.2 CentOS/RHEL

```bash
# 更新系统
sudo yum update -y

# 安装基础依赖
sudo yum install -y gcc gcc-c++ make cmake git

# 安装序列化库
sudo yum install -y protobuf-devel protobuf-compiler flatbuffers-devel

# 安装日志库
sudo yum install -y spdlog-devel

# 安装网络库
sudo yum install -y boost-devel

# 安装安全库
sudo yum install -y openssl-devel

# 安装其他依赖
sudo yum install -y ncurses-devel
```

### 2.2 QNX平台

#### 2.2.1 QNX开发环境

1. **安装QNX SDP 7.1+**：从QNX官方网站下载并安装QNX Software Development Platform
2. **设置环境变量**：
   ```bash
   export QNX_HOST=/path/to/qnx710/host/linux/x86_64
   export QNX_TARGET=/path/to/qnx710/target/qnx7
   export PATH=$QNX_HOST/usr/bin:$PATH
   ```
3. **安装依赖**：
   - 确保QNX开发环境中已包含必要的开发库

### 2.3 Windows平台

#### 2.3.1 基础依赖

1. **安装Visual Studio 2019+**：
   - 从Microsoft官网下载并安装Visual Studio 2019或更高版本
   - 选择"使用C++的桌面开发"工作负载

2. **安装CMake 3.16+**：
   - 从CMake官网下载并安装CMake 3.16或更高版本
   - 将CMake添加到系统环境变量

3. **安装Git**：
   - 从Git官网下载并安装Git

4. **安装依赖库**：
   - **Protobuf**：从GitHub下载并编译安装
   - **FlatBuffers**：从GitHub下载并编译安装
   - **spdlog**：从GitHub下载并编译安装
   - **OpenSSL**：从官网下载并安装

### 2.4 macOS平台

#### 2.4.1 基础依赖

## 4. 编译构建

### 4.1 使用AuroraBuild编译系统

AuroraRT使用自研的AuroraBuild编译系统，支持多语言混合编译、并行构建和跨平台支持。

#### 4.1.1 安装AuroraBuild

```bash
# 克隆AuroraBuild代码
git clone https://github.com/your-org/aurorabuild.git
cd aurorabuild

# 编译安装
mkdir build
cd build
cmake .. -DCMAKE_BUILD_TYPE=Release
make -j$(nproc)
sudo make install
```

#### 4.1.2 使用AuroraBuild构建AuroraRT

```bash
# 进入AuroraRT目录
cd aurorart

# 使用AuroraBuild构建
aurorabuild build

# 安装
aurorabuild install
```

### 4.2 传统CMake构建

#### 4.2.1 Linux平台

```bash
# 创建构建目录
mkdir build && cd build

# 配置CMake
cmake .. -DCMAKE_BUILD_TYPE=Release

# 编译
make -j$(nproc)

# 安装
sudo make install
```

#### 4.2.2 QNX平台

```bash
# 创建构建目录
mkdir build && cd build

# 配置CMake（使用QNX工具链）
cmake .. -DCMAKE_BUILD_TYPE=Release -DCMAKE_TOOLCHAIN_FILE=../cmake/qnx.toolchain.cmake

# 编译
make -j4

# 安装
make install
```

#### 4.2.3 Windows平台

##### 4.2.3.1 使用Visual Studio

1. **打开CMake GUI**：
   - 选择源代码目录和构建目录
   - 点击"Configure"，选择Visual Studio版本
   - 点击"Generate"

2. **编译**：
   - 打开生成的解决方案文件（.sln）
   - 选择"Release"配置
   - 点击"生成" > "生成解决方案"

3. **安装**：
   - 右键点击"INSTALL"项目，选择"生成"

##### 4.2.3.2 使用命令行

```powershell
# 创建构建目录
mkdir build
cd build

# 配置CMake
cmake .. -DCMAKE_BUILD_TYPE=Release

# 编译
cmake --build . --config Release

# 安装
cmake --install .
```

#### 4.2.4 macOS平台

```bash
# 创建构建目录
mkdir build && cd build

# 配置CMake
cmake .. -DCMAKE_BUILD_TYPE=Release

# 编译
make -j$(sysctl -n hw.ncpu)

# 安装
sudo make install
```

#### 4.2.5 AUTOSAR平台

```bash
# 创建构建目录
mkdir build && cd build

# 配置CMake（使用AUTOSAR工具链）
cmake .. -DCMAKE_BUILD_TYPE=Release -DCMAKE_TOOLCHAIN_FILE=../cmake/autosar.toolchain.cmake

# 编译
make -j4

# 安装
make install
```

## 5. 环境变量配置

### 5.1 Linux/macOS

```bash
# 编辑环境变量文件
echo 'export AURORART_HOME=/usr/local/aurorart' >> ~/.bashrc
echo 'export PATH=$AURORART_HOME/bin:$PATH' >> ~/.bashrc
echo 'export LD_LIBRARY_PATH=$AURORART_HOME/lib:$LD_LIBRARY_PATH' >> ~/.bashrc
echo 'export AURORART_TOOL_PATH=$AURORART_HOME/tools:$PATH' >> ~/.bashrc
echo 'export AURORART_PLUGIN_PATH=$AURORART_HOME/plugins' >> ~/.bashrc

# 生效环境变量
source ~/.bashrc
```

### 5.2 Windows

1. **打开环境变量设置**：
   - 右键点击"此电脑" > "属性" > "高级系统设置" > "环境变量"

2. **添加系统变量**：
   - **AURORART_HOME**：C:\Program Files\AuroraRT
   - **AURORART_TOOL_PATH**：%AURORART_HOME%\tools
   - **AURORART_PLUGIN_PATH**：%AURORART_HOME%\plugins

3. **修改Path变量**：
   - 添加 %AURORART_HOME%\bin
   - 添加 %AURORART_TOOL_PATH%

## 10. 零拷贝配置

### 10.1 共享内存配置

```bash
# 配置共享内存大小
echo 'kernel.shmmax=134217728' | sudo tee -a /etc/sysctl.conf
echo 'kernel.shmall=32768' | sudo tee -a /etc/sysctl.conf
sudo sysctl -p

# 检查共享内存配置
ipcs -lm
```

### 10.2 大页内存配置

```bash
# 配置大页内存
echo 'vm.nr_hugepages=1024' | sudo tee -a /etc/sysctl.conf
sudo sysctl -p

# 检查大页内存
cat /proc/meminfo | grep HugePages
```

## 12. 常见问题

### 12.1 编译错误

#### 12.1.1 缺少依赖

- **问题**：编译时提示缺少头文件或库
- **解决**：确保所有依赖库已正确安装，检查CMake配置

#### 12.1.2 版本不兼容

- **问题**：依赖库版本与AuroraRT要求不匹配
- **解决**：安装指定版本的依赖库，或修改CMake配置以适应现有版本

#### 12.1.3 AuroraBuild命令未找到

- **问题**：执行aurorabuild命令时提示未找到
- **解决**：确保AuroraBuild已正确安装并添加到PATH环境变量

### 12.2 运行错误

#### 12.2.1 库文件找不到

- **问题**：运行时提示找不到库文件
- **解决**：确保LD_LIBRARY_PATH（Linux/macOS）或PATH（Windows）包含AuroraRT库目录

#### 12.2.2 权限问题

- **问题**：创建共享内存或网络套接字时权限不足
- **解决**：以管理员权限运行，或修改系统权限设置

#### 12.2.3 零拷贝失败

- **问题**：零拷贝传输失败
- **解决**：检查共享内存配置，确保共享内存大小足够，检查权限设置

### 12.3 网络问题

#### 12.3.1 多播功能不可用

- **问题**：节点发现失败，多播功能不可用
- **解决**：检查网络配置，确保多播功能已启用

#### 12.3.2 防火墙阻止

- **问题**：网络通信被防火墙阻止
- **解决**：配置防火墙规则，允许AuroraRT使用的端口

## 13. 总结

AuroraRT 车载实时消息中间件的环境搭建包括系统要求、依赖项安装、源码获取、编译构建、环境变量配置和验证安装等步骤。通过正确的环境搭建，可以确保AuroraRT在不同平台上正常运行，为车载系统提供可靠的实时通信服务。

在搭建环境时，应注意以下几点：
- 确保系统满足AuroraRT的硬件和软件要求
- 正确安装所有必要的依赖库
- 按照平台特定的编译步骤进行构建
- 配置正确的环境变量
- 验证安装是否成功
- 配置零拷贝相关的系统设置
- 配置网络相关的设置

通过遵循本指南的步骤，可以快速搭建AuroraRT的开发和运行环境，为后续的开发和测试工作做好准备。同时，充分利用AuroraBuild编译系统和AuroraCLI工具系统，可以提高开发效率和系统管理能力。
