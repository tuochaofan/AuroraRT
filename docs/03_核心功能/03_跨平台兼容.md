# 跨平台兼容

## 1. 模块概述

跨平台兼容是AuroraRT 车载实时消息中间件的核心功能之一，旨在屏蔽不同操作系统平台的差异，确保中间件在Linux、QNX、Windows、macOS和VxWorks等不同平台上的行为一致，为上层应用提供统一的接口。

## 2. 设计理念

### 2.1 核心设计目标
  - **平台无关**：核心业务逻辑不依赖于具体平台
  - **统一接口**：为上层应用提供统一的API接口
  - **行为一致**：在不同平台上的行为保持一致
  - **性能优化**：针对不同平台进行性能优化

### 2.2 设计原则
  - **抽象隔离**：通过抽象层隔离平台差异
  - **条件编译**：使用条件编译处理平台特定代码
  - **统一配置**：提供统一的配置机制，适配不同平台
  - **渐进增强**：在保持核心功能一致的基础上，利用平台特性进行优化

## 3. 技术实现

### 3.1 平台抽象层

AuroraRT实现了一套完整的平台抽象层，支持以下平台：
- Linux
- QNX Neutrino RTOS
- Windows
- macOS
- VxWorks
- AUTOSAR

#### 3.1.1 线程抽象
  - **实现方式**：基于pthread和平台特定API，实现了统一的线程管理接口
  - **核心功能**：
    - 线程创建和管理
    - 线程优先级设置
    - 线程亲和性设置
    - 线程同步原语（互斥锁、条件变量）
    - 线程池管理（Linux平台）

#### 3.1.2 内存抽象
  - **实现方式**：基于平台特定内存管理API，实现了统一的内存管理接口
  - **核心功能**：
    - 内存分配和释放
    - 内存池管理（Linux平台）
    - 共享内存管理
    - 内存锁定（mlock/mlockall）

#### 3.1.3 网络抽象
  - **实现方式**：基于Socket API，实现了统一的网络I/O接口
  - **核心功能**：
    - Socket创建和管理
    - 网络I/O操作
    - 网络地址和端口处理
    - 网络选项设置

#### 3.1.4 时间抽象
  - **实现方式**：封装平台特定的时间获取API，提供统一的时间接口
  - **核心功能**：
    - 系统时间获取
    - 高精度计时（使用汇编实现的时间戳获取）
    - 定时器管理

### 3.2 平台特性检测

#### 3.2.1 编译时检测
  - **实现方式**：使用预处理器宏进行编译时平台检测
  - **技术要点**：
    - 定义平台检测宏，如`__linux__`、`__QNX__`、`_WIN32`、`__APPLE__`、`__VXWORKS__`
    - 使用条件编译，隔离平台特定代码

#### 3.2.2 运行时检测
  - **实现方式**：实现了PlatformCapabilitiesManager单例类，提供运行时平台能力检测
  - **核心功能**：
    - 检测当前运行平台
    - 检测硬件特性（TSN、SSE2、AVX、AVX2、AVX512、NEON）
    - 检测平台能力（共享内存、实时调度、CPU亲和性、内存锁定、高精度定时器、零拷贝、无锁队列）
    - 提供平台特定的配置和优化

### 3.3 平台差异适配

### 3.4 原子操作实现

AuroraRT实现了跨平台的原子操作接口，支持以下操作：
- 原子比较交换
- 原子存储
- 原子加载
- 原子加法
- 原子减法
- 原子与操作
- 原子或操作
- 原子异或操作

### 3.5 TSN支持

AuroraRT在各平台上实现了TSN（时间敏感网络）支持：
- **Linux**：通过检查网络设备特性和ethtool命令检测TSN支持
- **QNX**：利用QNX对TSN的原生支持
- **macOS**：检查系统版本是否支持TSN
- **Windows**：通过网络适配器信息和注册表检测TSN支持
- **AUTOSAR**：利用AUTOSAR通信栈对TSN的支持

## 4. 核心功能

### 4.1 平台无关的线程管理
  - **功能**：提供统一的线程创建、管理和同步接口
  - **使用方式**：
    ```cpp
    // 创建线程
    void* thread = platform->createThread(threadFunc, arg);
    
    // 创建带优先级的线程
    void* threadWithPriority = platform->createThreadWithPriority(threadFunc, arg, 80);
    
    // 设置线程优先级
    platform->setThreadPriority(thread, 80);
    
    // 设置线程亲和性
    platform->setThreadAffinity(thread, 0);
    
    // 等待线程结束
    platform->joinThread(thread);
    ```

### 4.2 平台无关的内存管理
  - **功能**：提供统一的内存分配、释放和管理接口
  - **使用方式**：
    ```cpp
    // 分配内存
    void* buffer = platform->allocateMemory(1024);
    
    // 使用内存
    memcpy(buffer, "Hello, AuroraRT!", 14);
    
    // 释放内存
    platform->freeMemory(buffer);
    
    // 创建共享内存
    void* sharedMem = platform->createSharedMemory("aurora_shm", 1024 * 1024);
    
    // 映射共享内存
    void* mappedMem = platform->mapSharedMemory("aurora_shm", 1024 * 1024);
    
    // 解除映射共享内存
    platform->unmapSharedMemory(mappedMem, 1024 * 1024);
    
    // 销毁共享内存
    platform->destroySharedMemory("aurora_shm");
    ```

### 4.3 平台无关的网络I/O
  - **功能**：提供统一的网络Socket创建、管理和I/O操作接口
  - **使用方式**：
    ```cpp
    // 创建Socket
    int sockfd = platform->createSocket(AF_INET, SOCK_STREAM, 0);
    
    // 设置非阻塞模式
    platform->setSocketNonBlocking(sockfd);
    
    // 设置地址重用
    platform->setSocketReuseAddr(sockfd);
    
    // 关闭Socket
    platform->closeSocket(sockfd);
    ```

### 4.4 平台无关的时间操作
  - **功能**：提供统一的时间获取和定时器管理接口
  - **使用方式**：
    ```cpp
    // 获取高精度时间戳（微秒）
    uint64_t timestamp = platform->getTimestampUs();
    ```

### 4.5 平台能力检测
  - **功能**：提供平台能力和硬件特性检测接口
  - **使用方式**：
    ```cpp
    // 获取平台能力
    PlatformCapabilities caps = getPlatformCapabilities();
    
    // 检查是否支持共享内存
    bool hasSharedMemory = hasSharedMemorySupport();
    
    // 检查是否支持实时调度
    bool hasRealtimeScheduling = hasRealtimeSchedulingSupport();
    
    // 检查是否支持零拷贝
    bool hasZeroCopy = hasZeroCopySupport();
    
    // 获取硬件特性字符串
    std::string features = getHardwareFeaturesString();
    
    // 检查特定硬件特性
    bool hasTSN = hasHardwareFeature("TSN");
    ```

## 7. 使用方法

### 7.1 平台抽象层使用

#### 7.1.1 线程管理

```cpp
// 获取平台实例
auto* platform = PlatformManager::instance().getPlatform();

// 创建线程
void* thread = platform->createThread([](void* arg) {
    std::cout << "Thread started" << std::endl;
    // 线程逻辑
    return nullptr;
}, nullptr);

// 设置线程优先级
platform->setThreadPriority(thread, 80);

// 设置线程亲和性
platform->setThreadAffinity(thread, 0);

// 等待线程结束
platform->joinThread(thread);
```

#### 7.1.2 内存管理

```cpp
// 获取平台实例
auto* platform = PlatformManager::instance().getPlatform();

// 分配内存
void* buffer = platform->allocateMemory(1024);

// 使用内存
memcpy(buffer, "Hello, AuroraRT!", 14);

// 释放内存
platform->freeMemory(buffer);

// 创建共享内存
void* sharedMem = platform->createSharedMemory("aurora_shm", 1024 * 1024);
if (sharedMem) {
    // 使用共享内存
    memcpy(sharedMem, "Shared memory test", 17);
    
    // 销毁共享内存
    platform->destroySharedMemory("aurora_shm");
}
```

#### 7.1.3 网络管理

```cpp
// 获取平台实例
auto* platform = PlatformManager::instance().getPlatform();

// 创建Socket

if (sockfd >= 0) {
    // 设置非阻塞模式
    platform->setSocketNonBlocking(sockfd);
    
    // 设置地址重用
    platform->setSocketReuseAddr(sockfd);
    
    // 关闭Socket
    platform->closeSocket(sockfd);
}
```

## 10. 总结

跨平台兼容模块是AuroraRT 车载实时消息中间件的核心功能之一，通过平台抽象层和条件编译，屏蔽了不同操作系统平台的差异，为上层应用提供了统一的API接口。该模块不仅确保了中间件在Linux、QNX、Windows、macOS和VxWorks等不同平台上的行为一致，还针对不同平台进行了性能优化，充分利用了平台特性。

通过合理的抽象设计和平台适配，跨平台兼容模块使得AuroraRT能够在不同的车载计算平台上无缝运行，为车载系统的开发者提供了便捷、一致的开发体验，同时也为AuroraRT的未来扩展性奠定了基础。

该模块的设计充分考虑了实时系统的需求，特别是在QNX等实时操作系统上的性能优化，确保了AuroraRT在车载环境中的实时性和可靠性。同时，通过硬件特性检测，AuroraRT能够根据不同平台的硬件能力进行自适应优化，进一步提高系统性能。
