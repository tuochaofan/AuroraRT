# AuroraRT 术语表

## 1. 核心概念

| 术语 | 解释 |
|------|------|
| AuroraRT | 面向车载自动驾驶、工业控制、边缘计算三大核心场景的实时消息中间件 |
| 零拷贝 | 基于共享内存的技术，减少数据传输中的内存拷贝，降低延迟 |
| 无锁队列 | 基于原子操作和内存屏障实现的队列，避免使用互斥锁，提高并发性能 |
| 内存池 | 预分配内存块的集合，用于高效管理内存分配和释放 |
| 多级内存池 | 根据不同大小的内存需求，使用不同的内存池 |
| 共享内存 | 多个进程可以访问的内存区域，用于进程间通信 |
| 实时调度 | 确保关键任务优先执行的调度策略，如SCHED_FIFO |
| 低抖动 | 延迟的变化范围小，确保实时任务的确定性 |
| 节点 | AuroraRT中的基本功能单元，具有唯一的ID和名称 |
| 域 | 逻辑上的网络分区，用于管理和隔离资源 |
| 分区 | 域内的进一步细分，用于更细粒度的资源管理 |

## 2. 通信模式

| 术语 | 解释 |
|------|------|
| 发布-订阅模式 | 基于主题的消息发布和订阅机制，发布者和订阅者互不感知 |
| 请求-响应模式 | 基于服务的请求和响应机制，客户端发送请求，服务端返回响应 |
| 事件模式 | 基于事件的消息通知机制，通知者发送事件，监听器接收事件 |
| 推送-拉取模式 | 基于队列的消息推送和拉取机制，推送者推送数据，拉取者拉取数据 |

## 3. 传输方式

| 术语 | 解释 |
|------|------|
| 进程内通信 | 同一进程内不同模块之间的通信，使用无锁队列实现 |
| 跨进程通信 | 同一主机上不同进程之间的通信，使用共享内存实现 |
| 跨节点通信 | 不同主机之间的通信，使用网络协议实现 |
| 智能传输选择 | 根据消息特性和网络状况，选择最优的传输方式 |

## 4. 平台相关

| 术语 | 解释 |
|------|------|
| 平台抽象层 | 屏蔽不同操作系统平台差异的抽象层，提供统一接口 |
| 平台特性检测 | 检测当前运行平台的能力和硬件特性 |
| 平台差异适配 | 针对不同平台的特性进行适配，确保行为一致 |
| TSN | 时间敏感网络（Time-Sensitive Networking），用于保障实时数据传输的确定性 |
