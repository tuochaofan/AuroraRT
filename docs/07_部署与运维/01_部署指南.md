# 部署指南

## 1. 环境准备

### 1.1 系统要求

| 平台 | 版本要求 | 推荐配置 |
|------|---------|----------|
| Linux | Ubuntu 20.04+ | 4核CPU，8GB内存，50GB磁盘 |
| QNX | QNX 7.1+ | 4核CPU，4GB内存，30GB磁盘 |
| Windows | Windows 10+ | 4核CPU，8GB内存，50GB磁盘 |
| macOS | macOS 10.15+ | 4核CPU，8GB内存，50GB磁盘 |
| VxWorks | VxWorks 7.0+ | 4核CPU，4GB内存，30GB磁盘 |
| AUTOSAR | AUTOSAR 4.3.1+ | 4核CPU，4GB内存，30GB磁盘 |

### 1.2 依赖项

| 依赖 | 版本要求 | 用途 |
|------|---------|------|
| CMake | 3.16+ | 构建系统 |
| C++17 | 支持C++17的编译器 | 核心语言 |
| pthread | - | 线程支持（Linux/QNX/macOS） |

| libtsn | 1.0.0+ | TSN网络支持（可选） |

## 2. 编译安装

### 2.1 使用AuroraBuild编译系统

AuroraRT使用自研的AuroraBuild编译系统，支持多语言混合编译、并行构建和跨平台支持。

#### 2.1.1 安装AuroraBuild

```bash
# 克隆AuroraBuild代码
git clone https://github.com/your-org/aurorabuild.git
cd aurorabuild

# 编译安装
mkdir build
cd build
cmake .. -DCMAKE_BUILD_TYPE=Release
make -j$(nproc)
sudo make install
```

#### 2.1.2 使用AuroraBuild构建AuroraRT

```bash
# 克隆AuroraRT代码
git clone https://github.com/your-org/aurorart.git
cd aurorart

# 使用AuroraBuild构建
aurorabuild build

# 安装
aurorabuild install
```

### 2.2 传统CMake构建

## 3. 配置

### 3.1 配置文件

AuroraRT使用JSON格式的配置文件，默认路径为：
- Linux/QNX/macOS：`/etc/aurorart/config.json`
- Windows：`C:\Program Files\AuroraRT\config.json`
- AUTOSAR：`/opt/aurorart/config.json`

### 3.2 配置示例

```json
{
  "general": {
    "log_level": "info",
    "log_file": "/var/log/aurorart.log",
    "node_id": "node-001",
    "node_name": "sensor-node"
  },
  "network": {
    "multicast_address": "239.255.0.1",
    "multicast_port": 5555,
    "enable_multicast": true,
    "enable_tsn": false,
    "tsn_config": {
      "time_sync": true,
      "slot_scheduling": false
    }
  },
  "memory": {
    "memory_pool_size": 67108864,  // 64MB
    "shared_memory_size": 134217728,  // 128MB
    "enable_memory_pool": true,
    "enable_huge_pages": false,
    "zero_copy": {
      "enable": true,
      "max_message_size": 1048576,  // 1MB
      "buffer_count": 128
    }
  },
  "scheduling": {
    "realtime_priority": 90,
    "enable_realtime": true,
    "cpu_affinity": [0, 1]
  },
  "transport": {
    "enable_shared_memory": true,
    "enable_network": true,
    "protocols": ["shm", "udp", "tcp", "quic"],
    "default_protocol": "shm"
  },
  "security": {
    "enable_authentication": false,
    "enable_encryption": false,
    "tls_cert": "/etc/aurorart/certs/server.crt",
    "tls_key": "/etc/aurorart/certs/server.key",
    "ca_cert": "/etc/aurorart/certs/ca.crt"
  },
  "discovery": {
    "enable_service_discovery": true,
    "discovery_type": "centralized",  // centralized, decentralized
    "discovery_server": "127.0.0.1:5556"
  },
  "serialization": {
    "default_serializer": "flatbuffers",  // cdr, protobuf, flatbuffers, yas
    "enable_zero_copy_serialization": true
  }
}
```

### 3.3 环境变量

| 环境变量 | 描述 | 默认值 |
|---------|------|--------|
| AURORART_CONFIG | 配置文件路径 | 见上文 |
| AURORART_LOG_LEVEL | 日志级别 | info |
| AURORART_LOG_FILE | 日志文件路径 | 见上文 |
| AURORART_NODE_ID | 节点ID | 自动生成 |
| AURORART_NODE_NAME | 节点名称 | 自动生成 |
| AURORART_TOOL_PATH | 工具系统路径 | /usr/local/bin |
| AURORART_PLUGIN_PATH | 插件路径 | /usr/local/lib/aurorart/plugins |

## 6. 集成到应用

### 6.1 C++应用集成

#### 6.1.1 包含头文件

```cpp
#include <aurorart/aurorart.h>
```

#### 6.1.2 链接库

```bash
# CMake
find_package(AuroraRT REQUIRED)
target_link_libraries(your_app AuroraRT::aurorart)

# 或直接链接
g++ -o your_app your_app.cpp -l aurorart
```

#### 6.1.3 示例代码

```cpp
#include <aurorart/aurorart.h>
#include <iostream>

int main() {
    // 初始化AuroraRT
    aurorart::init();
    
    // 创建节点
    auto node = aurorart::node::NodeManager::instance().createNode("test_node");
    node->start();
    
    // 创建发布者
    auto pubSubPattern = std::make_shared<aurorart::communication::PubSubPattern>();
    pubSubPattern->init();
    pubSubPattern->start();
    
    // 使用零拷贝发布
    auto publisher = pubSubPattern->createPublisher<std::string>("test_topic");
    
    // 发布消息
    std::string message = "Hello, AuroraRT!";
    publisher->publish(&message, sizeof(message));
    std::cout << "Published message: " << message << std::endl;
    
    // 清理资源
    pubSubPattern->stop();
    node->stop();
    aurorart::shutdown();
    
    return 0;
}
```

## 7. 常见问题

### 7.1 编译错误

- **问题**：找不到依赖库
  **解决**：确保所有依赖库已正确安装，检查CMake配置或AuroraBuild配置

- **问题**：编译失败，提示缺少头文件
  **解决**：检查包含路径，确保依赖库的头文件可访问

- **问题**：AuroraBuild命令未找到
  **解决**：确保AuroraBuild已正确安装并添加到PATH环境变量

### 7.2 运行错误

- **问题**：服务启动失败
  **解决**：检查配置文件，查看日志了解具体错误

- **问题**：节点无法发现
  **解决**：检查网络连接，确保多播功能正常，检查服务发现配置

- **问题**：内存分配失败
  **解决**：调整内存池大小，确保系统有足够的内存，启用内存池预分配

- **问题**：零拷贝传输失败
  **解决**：检查共享内存配置，确保共享内存大小足够，检查权限设置

### 7.3 性能问题

- **问题**：延迟过高
  **解决**：启用实时调度，调整内存池配置，使用共享内存传输，启用零拷贝

- **问题**：吞吐量低
  **解决**：启用批量处理，优化消息大小，使用共享内存传输，启用零拷贝序列化

- **问题**：CPU使用率高
  **解决**：调整线程池大小，优化调度策略，使用CPU亲和性

## 8. 故障排查

### 8.1 日志分析

AuroraRT的日志文件包含详细的运行信息，可用于排查故障：

```bash
# 查看日志
cat /var/log/aurorart.log

# 过滤错误信息
grep "ERROR" /var/log/aurorart.log

# 查看最近的日志
tail -n 100 /var/log/aurorart.log

# 使用AuroraCLI查看日志
aurora core logs
```

### 8.2 网络诊断

```bash
# 检查网络连接
ping <other-node-ip>

# 检查多播功能
iperf -c 239.255.0.1 -u -T 1 -t 10

# 检查端口占用
netstat -tuln | grep 5555

# 检查TSN网络（如果启用）
tsn-tool status
```

### 8.3 内存诊断

```bash
# 检查内存使用情况

# 检查共享内存

# 检查进程内存使用

# 使用AuroraCLI检查内存状态

```

```bash
# 检查共享内存段
ipcs -m | grep aurorart

```

## 9. 升级

### 9.1 升级步骤

1. **备份配置文件**：
   ```bash
   cp /etc/aurorart/config.json /etc/aurorart/config.json.bak
   ```

2. **停止服务**：
   ```bash
   aurora core stop
   ```

3. **更新代码**：
   ```bash
   cd aurorart
   git pull
   ```

4. **重新编译安装**：
   ```bash
   aurorabuild build
   aurorabuild install
   ```

5. **恢复配置文件**：
   ```bash
   cp /etc/aurorart/config.json.bak /etc/aurorart/config.json
   ```

6. **启动服务**：
   ```bash
   aurora core start
   ```

### 9.2 版本兼容性

AuroraRT遵循语义化版本控制，确保向后兼容性：

- 补丁版本（x.y.z）：修复bug，无兼容性问题
- 次版本（x.y.0）：新增功能，向后兼容
- 主版本（x.0.0）：可能包含破坏性变更

## 10. 卸载

### 10.1 Linux/QNX/macOS

```bash
# 停止服务
aurora core stop

# 卸载
aurorabuild uninstall

# 或使用传统方式
sudo make uninstall  # 从build目录执行

# 清理配置文件
sudo rm -rf /etc/aurorart

# 清理日志
sudo rm -rf /var/log/aurorart.log

# 清理工具系统
sudo rm -rf /usr/local/bin/aurora*
sudo rm -rf /usr/local/lib/aurorart
```

### 10.2 Windows

```powershell
# 停止服务
Stop-Service AuroraRT

# 卸载
# 通过控制面板或安装程序卸载

# 清理配置文件
Remove-Item -Path "C:\Program Files\AuroraRT\config.json" -Force

# 清理日志
Remove-Item -Path "C:\ProgramData\AuroraRT\logs" -Recurse -Force

# 清理工具系统
Remove-Item -Path "C:\Program Files\AuroraRT\bin\aurora*.exe" -Force
```

### 10.3 AUTOSAR平台

```bash

# 卸载
sudo make uninstall  # 从build目录执行

# 清理配置文件
```
